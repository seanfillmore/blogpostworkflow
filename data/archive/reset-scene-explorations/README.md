# Reset scene explorations — abandoned

Two AI-generated counter-scene frames and their prompt, produced during the
90-Day Coconut Reset lander work (2026-08-04) by
`data/brand/frames/meta-reset/gen-scene-counter.mjs`.

**Nothing imports them.** The shipped Meta statics are the composited
product-cutout frames in `data/brand/frames/meta-reset/`, not these. This was a
direction that was tried and dropped.

Archived rather than deleted for the reason this directory exists, and the same
reason `generated-pdp-frames/` is here: image generation is non-deterministic,
so re-running `gen-scene-counter.mjs` with the identical prompt returns a
different picture. The prompt that produced them is kept alongside, so the
*intent* is reproducible even though the frames are not.

Safe to delete if the scene direction is never revisited.
