**Survivor setup.** Created `sets-and-bundles` (smart, `tag equals bundle`, 10 products).
Rewrote `non-toxic-body-lotion`'s rule from `tag equals "Hydrating Coconut Body Lotion"` — which
matched only one product — to `tag equals "Paraben-Free Lotion"`, which matches both lotion SKUs.
Added `foam-soap-refill-32oz` to `foaming-hand-soap` via a collect. Prepended above-the-fold PDP

## Baseline for the 28-day read

The 90 days before this change: **71 collection URLs, 93,785 impressions, 51 clicks — 0.054%
CTR**, with 57 of those URLs earning zero clicks. The lotion cluster alone ran 29 URLs for
59,616 impressions and 38 clicks. PDPs over the same window: 22,257 impressions, 8 clicks.

`logChangeEvent` windows opened for both category survivors and the four PDPs that now receive
single-SKU category traffic.

**Caveat on measurement, carried from the toothpaste consolidation:** `change-log`'s
`captureBaseline` reads GSC daily snapshots, which store only top pages, so a low-ranking
collection gets an `impr=0` baseline. **The trustworthy signal is rank-tracker on the query, not
the change-log window.**

## What this does not prove

Consolidation concentrates signal; it does not by itself convert impressions to revenue. These
pages ranked at positions 25–62, and nothing on page 3+ gets clicked regardless of page type.
The hypothesis under test is that collapsing 29 lotion URLs into one lifts position enough to
matter. A null result at 28 days is a real outcome to record, not a failure to explain away.
