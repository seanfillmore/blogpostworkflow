## Two habits this session kept rewarding

- **Local green ≠ production green.** Three separate times, tests passed in the checkout and failed on the box, because the committed mirrors are older than the server's. Run the suite **on the server** before believing it.
- **Assert outcomes, not pre-states.** Every mirror test that broke did so by asserting "the BEFORE is present" — true only until the remediation shipped. `before + after === expectedOccurrences` survives reconciliation; the strict form does not.
